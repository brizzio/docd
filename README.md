# doc.do — Landing Page

Landing page estática pronta para GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `docdo`).
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve. Em alguns instantes o GitHub exibirá a URL pública.

Não há build, dependências ou servidor: é HTML/CSS/JS puro.

## Estrutura

- `index.html` — conteúdo da página
- `styles.css` — identidade visual e responsividade
- `script.js` — animações leves de entrada
- `assets/` — logos e QR de WhatsApp

## Contato

O botão de WhatsApp aponta para o mesmo link codificado no QR fornecido pela Bitsherpa.
